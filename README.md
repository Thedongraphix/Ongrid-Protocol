# 🌍 OnGrid Protocol (OGP)

## Introduction

**OnGrid Protocol (OGP)** bridges **real-world renewable energy projects** with **on-chain finance** through a secure, scalable **Layer 2 network**.
By integrating **DePIN devices**, **AI-driven insights**, and **Web3 infrastructure**, OGP enables the creation of a **sustainable, carbon-neutral energy economy** built by and for the community.

---

## 🌱 Mission & Vision

### **Mission**

To accelerate the global transition toward clean energy through decentralized technology, verifiable carbon credits, and community-driven governance on base

### **Vision**

A future where every renewable energy asset is transparently owned, optimized by AI, and tokenized on-chain — driving sustainable impact across the world.

---

## ⚙️ Core Features

* **🔗 Decentralized Asset Ownership** – Tokenize renewable energy infrastructure using ERC standards for transparent investment.
* **🤖 AI-Assisted Green Systems** – Real-time optimization for energy generation and consumption.
* **⚡ Scalable Layer 2 Transactions** – High-throughput, low-cost blockchain operations for energy data and token transfers.
* **🌐 DePIN Device Integration** – Connect IoT/Edge devices for carbon and power data synchronization.
* **💎 Carbon Credit Mining** – Generate verifiable carbon tokens through validated energy data.
* **🏛️ DAO Governance** – Community-led decision-making through decentralized governance and voting.

---

## 🧠 Why It Matters

The renewable energy sector suffers from **centralized control, opaque financing, and unverifiable carbon data**.
OGP solves this by enabling:

* **Transparent project ownership** via tokenization
* **AI-backed operational insights**
* **Verifiable on-chain carbon credits**
* **Community governance** for resource allocation and sustainability tracking

## 🛠️ Technologies Used

| Category                 | Technology                                | Purpose                                                    |
| ------------------------ | ----------------------------------------- | ---------------------------------------------------------- |
| **Blockchain Framework** | Ethereum / Base L2                        | Smart contract execution and scalability                   |
| **Smart Contracts**      | Solidity, Hardhat                         | Core logic for assets, governance, and carbon credits      |
| **DePIN Integration**    | IoT devices, MQTT, Edge AI                | Real-world data ingestion and verification                 |
| **AI Layer**             | Python (TensorFlow / PyTorch)             | Predictive analysis for optimization and yield forecasting |
| **Oracles**              | Chainlink / RedStone                      | Fetching off-chain environmental and carbon data           |
| **Storage Layer**        | IPFS / Filecoin                           | Decentralized energy data and metadata storage             |
| **Frontend**             | Next.js + TypeScript + Wagmi + RainbowKit | Web interface for project dashboard and interaction        |
| **Wallet Integration**   | MetaMask, Coinbase Wallet, WalletConnect  | Secure and seamless user onboarding                        |
| **Governance Layer**     | Snapshot / Tally                          | Decentralized decision-making for the DAO                  |

---

## 🧩 System Architecture (High-Level)

1. **DePIN Layer:** IoT devices collect renewable energy and carbon data.
2. **AI Layer:** Processes and optimizes data for energy yield and sustainability metrics.
3. **Blockchain Layer:** Records data, tokenizes assets, and facilitates DAO governance.
4. **User Layer:** Web3 dashboard for investors, contributors, and project operators.

## 🧑‍💻 How to Contribute

We welcome developers, researchers, and sustainability advocates to help shape the OnGrid ecosystem.

### 1. Fork the Repository

```bash
git clone https://github.com/<your-username>/ongrid-protocol.git
cd ongrid-protocol
```

### 2. Install Dependencies

```bash
npm install
# or
yarn install
```

### 3. Set Up Environment Variables

Create a `.env` file in the root directory and add the following:

```bash
PRIVATE_KEY=<your_private_key>
RPC_URL=<your_rpc_endpoint>
PINATA_API_KEY=<optional_for_ipfs_uploads>
```

### 4. Compile Smart Contracts

```bash
npx hardhat compile
```

### 5. Deploy to a Test Network

```bash
npx hardhat run scripts/deploy.js --network base-sepolia
```

### 6. Run the Frontend

```bash
cd frontend
npm run dev
```

Then visit **[http://localhost:3000](http://localhost:3000)**
